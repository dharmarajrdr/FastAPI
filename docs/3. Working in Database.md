# Working in Database

- We need `sqlalchemy` and `psycopg2` to work with database. So, let's install them using pip.

    ```bash
    pip install sqlalchemy psycopg2
    ```

    | Dependency | Purpose | Equivalent <br /> (in Java/Spring) |
    |------------|---------|-----------------------------|
    | `sqlalchemy` | It is an ORM (Object Relational Mapper) that allows us to interact with the database using Python objects instead of writing raw SQL queries. | Spring Data JPA |
    | `psycopg2` | It is a PostgreSQL database adapter for Python. It allows us to connect to a PostgreSQL database and execute SQL queries. | PostgreSQL JDBC Driver |

- Created [db_config.py](../db_config.py) file to configure the database connection and create a session.

    ```sql
    Indexes:
        "users_pkey" PRIMARY KEY, btree (id)
        "ix_users_email" UNIQUE, btree (email)

    ```


- Now, let's see how `sqlalchemy` helps in performing CRUD operations on the `users` table.

    1. To fetch all the users from the `users` table, we can use the following code:
    
        ```python
        users = db.query(User).all()
        ```

    2. To fetch a user by their ID, we can use the following code:
    
        ```python
        user = db.query(User).filter(User.id == user_id).first()
        ```

    3. To search for a user by their name, we can use the following code:
    
        ```python
        users = db.query(User).filter(User.name.ilike(f"%{name}%")).all()
        ```

- We don't need to write raw SQL queries to perform these operations. `sqlalchemy` takes care of generating the appropriate SQL queries for us.
