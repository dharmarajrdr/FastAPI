# Setup Playground

- **FastAPI** is a modern, fast (high-performance), web framework for building APIs with Python 3.6+ based on standard Python type hints.

- Since fast API helps to build web APIs, we need Web Server. If you have experience in Java, we use **Tomcat** as a web server. Similarly, in react, we use **Node.js** as a web server. 
- Likewise In Python, we use **Uvicorn** as a web server. Uvicorn is a lightning-fast ASGI server implementation, using `uvloop` and `httptools`.

- When you run `pip install fastapi`, it will install FastAPI globally in your system which may conflict with other projects. So, it is recommended to use **virtual environment** for each project. You can create a virtual environment using the following command:

    ```bash
    python -m venv venv
    ```

- Once the virtual environment is created, you can activate it using the following command:

    ```bash
    source venv/bin/activate
    ```

    - As soon as you activate the virtual environment, you will see the name of the virtual environment in your terminal prompt. 
    - This indicates that you are now working within the virtual environment.

- To deactivate the virtual environment, you can use the following command:

    ```bash
    deactivate
    ```

- Now, the virtual environment is activated, and we are ready to install FastAPI and Uvicorn. It is always a good practice to create a [requirements.txt](../requirements.txt) file and track the dependencies.

    | Dependency | Purpose |
    |------------|---------|
    | `fastapi`    | To build web APIs |
    | `uvicorn`    | To run the web server |

- To install the dependencies, run the following command:

    ```bash
    pip install -r requirements.txt
    ```

- To know the list of installed packages in the virtual environment, you can use the following command:

    ```bash
    pip list
    ```
